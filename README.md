# DBS Digital Business Store

Boutique en ligne officielle de **Digital Business Store**.

## Structure

- `index.html` — Page d'accueil
- `css/styles.css` — Styles principaux
- `js/` — Logique panier, produits, etc.
- `assets/` — Logo et images

## Fonctionnalités

- Design fidèle à la maquette
- Panier (localStorage)
- Sélecteurs langue + devise
- Bouton WhatsApp
- Numéro de commande unique
- Prêt pour suivi de commande et espace client

## Déploiement

Active GitHub Pages : Settings → Pages → Deploy from branch `main` / root.
